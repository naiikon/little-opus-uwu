# Bạch Tuộc Nhỏ UwU – bản Việt hóa (dùng riêng)

Bản gốc: 小章鱼UwU (mod máy Bạch Tuộc Phun Mực của 1900), https://uwu-79q.pages.dev
Bản này chỉ dịch giao diện và prompt sang tiếng Việt, không đổi tính năng.

## Lưu ý
- Tác giả gốc cho phép mod để **tự dùng**; muốn đăng công khai phải nhắn tác giả trước và không đăng ngoài Vĩ Ba Trấn.
- Các nhãn định dạng tin nhắn trong ngoặc vuông như `[Tên的消息：…]` được giữ tiếng Trung vì code dựa vào chúng để nhận diện tin nhắn.
- Dữ liệu không tự chuyển từ bản gốc sang: xuất file sao lưu `.ee` ở bản gốc rồi nhập vào bản này.
- Vẫn cần key đăng nhập của Vĩ Ba Trấn như bản gốc.

## Chạy
Đưa toàn bộ thư mục này lên GitHub Pages (hoặc host tĩnh bất kỳ), mở index.html.
